## 1. 지도 입력 위저드 — 왜 카카오맵이 아닌가

| | 카카오맵 연동 | **v3 채택: folium (OSM+Esri 위성)** |
|---|---|---|
| API 키 | 발급 + 도메인 등록 필요 | **불필요** |
| Streamlit 연동 | JS SDK 커스텀 컴포넌트 직접 제작 | `streamlit-folium` 검증된 패키지 |
| 배포 | 키 환경변수 관리 | requirements 2줄 추가로 끝 |
| 제출 1주 전 리스크 | 외부 승인 절차 의존 | 오늘 바로 배포 가능 |

**작동 방식** (➕탭 기본 모드, 7단계 위저드):
위치 찾기(위경도 붙여넣기 이동 지원) → ① 대지 다각형 → ② 신축 건물(외접 사각형 변환 + 높이·층수) → ③ 인접 건물 N개(표에서 이름·높이·층수) → ④ 도로 N개(형상 그대로 + 폭) → ⑤ 야적장 📍 → 확인·저장(로컬 좌표 미리보기 + 면적). 이전 단계 도형은 색깔 오버레이로 계속 표시.

**좌표 변환**: 대지 무게중심을 원점으로 한 국지 등장방형 근사 —
1° 위도 ≈ 111,132.92 − 559.82cos2φ + 1.175cos4φ (m), 1° 경도 ≈ 111,412.84cosφ − 93.5cos3φ (m).
진주 위도에서 동 100 m·북 80 m 왕복 변환 오차 **0.00 mm** (단위 테스트).

**정직한 한계**: 지도 영상 정합 때문에 절대좌표는 ±수 m. 모델이 쓰는 건 대지·건물·도로 간 **상대 기하**라 의사결정 보조에 충분하고, 위저드 마지막 화면에도 같은 주의문을 띄운다. 측량 좌표가 있으면 "✍️ 직접 입력(정밀)" 모드 — 기존 폼 그대로 유지.

## 3. 야적장 입력 + w(θ) 장미도

- 직접입력 폼: 도로 표 아래 "자재 야적장 (x, y)" 입력 추가. 기존 자동값(대지 서쪽 3 m)이 기본값.
- 지도 위저드: ⑤단계 📍 마커가 그대로 `material_yard`.
- 탭③ 운영 모드 결과에 expander "📊 적재 경로 체류분포 w(θ)": 막대=체류비중, 빨간선=방향별 취약면적(정규화), 캡션에 집중비 ×N.NN — "두 분포의 겹침이 위험"이라는 모델 논리를 한 그림으로. 논문 운영모드 절 그림으로 바로 캡처해 쓰면 됨.

3. **헤드리스 UI (AppTest)**: ⑴ 지도 모드 기본 부팅 예외 0 ⑵ 직접입력 전환 → 야적장 −25.0 입력 → 🚀 버튼 **실제 클릭** → 저장 JSON에 [−25.0, 0.0] 반영 + 사이드바 "⭐ E2E현장" 자동선택 ⑶ v2 사이드바 회귀 통과.

6. folium 지도 3모드(없음/다각형/마커) HTML 렌더 스모크 통과.

**샌드박스에서 못 한 것(정직)**: 실제 브라우저 마우스 드로잉(이 환경엔 브라우저가 없음 — 컴포넌트가 돌려주는 GeoJSON 파싱·변환·검증은 전부 테스트했고, 드로잉 UI 자체는 leaflet-draw 표준 플러그인). 배포 후 네가 위성사진에서 한 번 그려보는 게 마지막 확인.

## 7. 논문·발표 활용 포인트

- **그림 추가**: w(θ) 장미도(운영모드 근거), 지도 위저드 스크린샷(시스템 사용성 — "좌표 입력 장벽 제거"로 시스템 기여도 어필).
- **시스템 장 문장 예시**: "현장 적용성을 높이기 위해 위성영상 기반 도형 입력 인터페이스를 구현하였다. 사용자가 지도 위에 대지·인접건물·도로·야적장을 작도하면 부지중심 국지좌표계(m)로 자동 변환되며(왕복 변환 오차 < 1 cm), 좌표 측정 없이 임의 현장에 본 방법론을 적용할 수 있다."
- 발표 시연 동선 추천: 지도에서 학교 근처 아무 협소대지 하나를 라이브로 그려서 → 합의 최적화 → 설명 패널 + 장미도까지. "측정 없이 3분 만에 임의 부지 분석"이 가장 강한 데모.

## 7-1. 품질 패스 (2차 작업, 같은 날)

"수준급" 요구에 따라 이 환경에서 **눈으로 검증 가능한** 품질을 추가로 끌어올렸다.

1. **배포 중이던 진짜 버그 발견·수정 — UI 그림 한글 깨짐**: 한글 폰트 지정이 PDF 경로(`report_figures.py`)에만 있고 Streamlit UI 그림에는 없었다. 즉 배포 앱의 부지 미리보기·Pareto 그림에서 한글 라벨이 □로 깨질 수 있는 상태였다. 신규 `plot_style.py`가 fonts-nanum TTF를 matplotlib에 직접 등록(`addfont` — 폰트 캐시 미갱신 문제까지 회피)해 근본 해결.
2. **그림 테마 통일**: 네이비·골드 팔레트(히어로와 동일 톤), spine 정리, dpi 110, 범례·그리드 일관화. 대표 그림 3종(미리보기·Pareto·장미도)을 실제 렌더링해 직접 눈으로 검수하며 다듬음.
3. **장미도 결함 수정**: θ 글자가 나눔고딕에 없어 □로 깨지던 것을 mathtext($\theta$)로 교체, 범례 하단 재배치, **"야적장 방향(적재 권상 체류)" 화살표 주석** 추가 — 스파이크의 의미가 그림 안에서 읽힘.
4. **미리보기 라벨 보강**: 야적장 라벨 흰 배경, 신축 건물 라벨 추가.
5. **코드 품질**: ruff 전수 검사 — 심각 버그(F821/F811/E9) **0건**, 미사용 import 등 32건 정리.
6. **히어로 CSS 실제 렌더 검증**: weasyprint로 PNG를 떠서 그라데이션·배지·라운드가 의도대로 나오는 것을 확인. 모바일 미디어쿼리 추가(표준 문법이나 weasyprint가 해석 못 해 배포 후 확인 항목).
7. **재검증**: UI 스위트 3/3, 신사동 회귀 1.43 m 동일, deprecation 0건.
